# Contributing Guide

## Branch Naming

Use descriptive branch names:

- feature/<name>
- fix/<name>
- refactor/<name>
- docs/<name>
- test/<name>

Examples:

feature/authentication
feature/restaurant-search
fix/login-error
docs/api-reference

## Pull Requests

All changes should be submitted through a Pull Request.

Do not push directly to `main` for normal development work.
